สรุปผลตอบแทน

ข้อมูล NAV จาก SEC Open API (สำนักงาน ก.ล.ต.) · ผลตอบแทนคำนวณจาก NAV ต่อหน่วย ไม่รวมค่าธรรมเนียมซื้อขาย · แก้รายชื่อกองได้ที่ไฟล์ funds.csv ใน repo
